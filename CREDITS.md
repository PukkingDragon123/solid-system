## Metadata and trivia

Song titles, artists, release years, track lists, credits and pop-culture trivia in `src/content/trivia` are short factual data compiled by hand. Facts like these are not protected by copyright.

- No copyrighted recordings, lyrics, album artwork, logos or screenshots are included.
- Album sleeves for real releases are generated procedurally from the title.
- Lyric rounds use only the public-domain and original songs above.
- Names of artists, works and companies are used only to identify them. LARPED ONE OUT is not affiliated with or endorsed by any of them.

## Optional online services

These are only used when the server operator enables them (see README). They are off when `LOO_OFFLINE=1` or when no keys are set.

- **MusicBrainz**: release groups and track lists. The core data is CC0. Requests send a descriptive User-Agent and are paced to about 1 per second, per MusicBrainz's API rules.
- **Openverse / Wikimedia Commons / Jamendo**: openly licensed audio.
  - Each file's own licence is checked.
  - Only PD, CC0, CC BY and CC BY-SA files play, with attribution shown.
  - NonCommercial and NoDerivatives files are rejected, because quiz rounds clip, speed up and reverse audio and the game may be run commercially.
  - Files are streamed through a proxy and never stored.
- **Spotify Web API**: track titles and artists from a public playlist, with links back to Spotify.
  - No Spotify audio, artwork or previews are played or stored.
  - Operators must check Spotify's Developer Terms and Developer Policy before enabling this.
- **TMDB**: movie and TV titles and years. *This product uses the TMDB API but is not endorsed or certified by TMDB.*
- **Cover Art Archive**: not used. Its images belong to their rights holders and come with no reuse licence.
